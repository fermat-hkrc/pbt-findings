## Summary

`Ip6RuleMap::GetNetworkAddress` builds an IPv6 network key by indexing
`in6_addr.s6_addr` with `prefixLen / 8` and **no upper bound**. On the
netfirewall SINGLE_IP install path, `InsertIp6SegBitmap` forwards
`NetFirewallIpParam.mask` (`uint8_t`, 0..255) into `OrInsert` without the
`mask > max` reject that IPv4 already has.

When `prefixLen ≥ 129`, `quotient ≥ 16` → **`s6_addr[16+]` OOB** and/or a
wrong network key → bitmap **OrInsert** merges the wrong rules. Legal
`/0`–`/128` is fine. Confirmed and fixed by developers
(`DTS2026081136698`).

Not High: needs `mask ∈ [129,255]` on a **SINGLE_IP** IPv6 rule; install is a
privileged netfirewall surface; MULTIPLE_IP uses `GetIp6AndMask` which emits
`prefixlen ≤ 128`.

## Vulnerable Code

`services/netmanagernative/bpf/include/bitmap_manager.h` —
`Ip6RuleMap::GetNetworkAddress` (~474–485):

```cpp
void GetNetworkAddress(in6_addr addr, int prefixLen, in6_addr &out)
{
    int quotient = prefixLen / 8;
    int remainder = prefixLen % 8;
    for (int i = 0; i < quotient; i++)
        out.s6_addr[i] = addr.s6_addr[i] & 0xff;   // OOB if quotient > 16
    if (remainder)
        out.s6_addr[quotient] = ...;                // OOB if quotient >= 16
}
```

Caller: `BitmapManager::InsertIp6SegBitmap` SINGLE_IP (~225–226) — **no**
mask check (IPv4 insert already rejects `mask > IPV4_MAX_PREFIXLEN`):

```cpp
ip6Map->OrInsert(item.ipv6.startIp, static_cast<uint32_t>(item.mask), bitmap);
```

Reachable path: parcel `ReadUint8(mask)` → `SetFirewallRules` →
`BuildBitmapMap` → `InsertIp6SegBitmap` SINGLE_IP.

Root cause: IPv6 network-key helper never bounds `prefixLen`; IPv6 insert
never got the IPv4-style max-prefix reject.

## Trigger Conditions

1. Netfirewall **SINGLE_IP** IPv6 rule with `mask ∈ [129, 255]`.
2. `InsertIp6SegBitmap` → `OrInsert` → `GetNetworkAddress(..., mask)`.
3. `quotient = prefixLen / 8 ≥ 16` → index past `s6_addr[15]`.

Unaffected: legal `/0`–`/128`; MULTIPLE_IP IPv6 (via `GetIp6AndMask`,
`prefixlen ≤ 128`); IPv4 path (already clamps / rejects).

## Impact

| Path | Result |
|------|--------|
| SINGLE_IP IPv6 rule, `mask > 128` | stack OOB on netsys rule install; or wrong `networkAddr` → **OrInsert** merges wrong rules |
| Legal `/0`–`/128` | OK |
| MULTIPLE_IP IPv6 | does not hit this alone |
| IPv4 `/0` / clamp | already fixed in same header |

Honest limits:
- Medium — privileged install path, specific illegal mask range, not every
  packet.
- OOB is on the **rule-install** SA path, not the eBPF per-packet match path.
- Why not High: needs attacker-or-bug-supplied `mask > 128` on SINGLE_IP IPv6;
  IPv4 already fail-closed.

## Minimal Counterexample

| prefixLen | quotient | Expected | Actual |
|----------:|---------:|----------|--------|
| 0..128 | 0..16 | OK | OK (`128` → remainder 0) |
| **129** | 16 | reject / no index | **`s6_addr[16]` OOB** |
| 255 | 31 | reject | OOB loop |

```text
mask = 129 (uint8_t from rule parcel)
GetNetworkAddress(..., 129) → write past in6_addr
```

## How PBT Detected This

Source-cited defect against production `bitmap_manager.h` /
`InsertIp6SegBitmap` (IPv4 sibling insert reject as local oracle). Harness
`pbt-native/get_network_address_pbt_test.cpp` is a placeholder; defect is not
a linked-SUT PBT FAIL.

| Claim | Holds |
|-------|-------|
| Real production SUT | `bitmap_manager.h:474–485` + insert ~225–226 |
| Concrete witness | `mask=129` → `quotient=16`, remainder write at `s6_addr[16]` |
| Local contract | IPv4 insert + IPv4 `GetNetworkAddress` siblings in same module |

## Suggested Fix

**One ticket, two sites** — match IPv4 insert reject + IPv4
`GetNetworkAddress` clamp/`/0` style. Prefer fail-closed at insert; still
bound the helper so any other caller cannot OOB.

### 1) `InsertIp6SegBitmap` — reject oversize mask (mirror IPv4)

```cpp
if (item.type == SINGLE_IP) {
    if (item.mask > IPV6_MAX_PREFIXLEN) {
        NETNATIVE_LOGE("InsertIp6SegBitmap: invalid mask %{public}u", item.mask);
        return NETFIREWALL_ERR;
    }
    ip6Map->OrInsert(item.ipv6.startIp, static_cast<uint32_t>(item.mask), bitmap);
    // ...
}
```

### 2) `Ip6RuleMap::GetNetworkAddress` — bound before index

```cpp
void GetNetworkAddress(in6_addr addr, int prefixLen, in6_addr &out)
{
    if (prefixLen < 0 || prefixLen > IPV6_MAX_PREFIXLEN) {
        return; /* out left zeroed */
    }
    if (prefixLen == 0) {
        return; /* /0 network key is all-zero */
    }
    int quotient = prefixLen / 8;
    int remainder = prefixLen % 8;
    // ... existing copy/mask loop ...
}
```

| After fix | Result |
|-----------|--------|
| SINGLE_IP `mask > 128` | `NETFIREWALL_ERR` at insert; no `OrInsert` |
| Helper `prefixLen` OOB / negative | early return; no `s6_addr[16+]` |
| Legal `/0`–`/128` | unchanged |
