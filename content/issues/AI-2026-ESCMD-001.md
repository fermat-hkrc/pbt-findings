## Summary

The `escape_md` helper inside `ParamCollectionSession.format_prompt` is not idempotent. Calling it twice produces different output than once — it escapes backslashes it previously inserted. Any workflow parameter prompt that is regenerated, retried, or re-displayed has its formatting progressively corrupted. Affects Telegram, Slack, and Email bot users.

## Vulnerable Code

`connect/client/workflows/param_collector.py:119-124`

```python
def escape_md(text: str) -> str:
    if not isinstance(text, str):
        text = str(text)
    for ch in ['_', '*', '`', '[', ']']:
        text = text.replace(ch, f'\\{ch}')
    return text
```

Call sites:
- `connect/adapters/channels/platforms/telegram/workflows/handlers/workflow_execute.py:48`
- `connect/adapters/channels/platforms/telegram/workflows/handlers/workflow_execute_collect.py:39`
- `connect/adapters/channels/platforms/slack/workflows/handlers/workflow_execute.py:39`
- `connect/adapters/channels/platforms/slack/workflows/handlers/workflow_execute_collect.py:30`
- `connect/adapters/channels/platforms/email/workflows/handlers/workflow_execute.py:37`
- `connect/adapters/channels/platforms/email/workflows/handlers/workflow_execute_collect.py:33`

## Root Cause

`escape_md` escapes `_`, `*`, `` ` ``, `[`, `]` but not `\`. After the first call, `"a_b"` → `"a\\_b"`. On the second call, `\_` is not recognized as already-escaped — `_` is still in the list, so it becomes `\\_`:

```
First call:   "a_b"    → "a\_b"
Second call:  "a\_b"   → "a\\_b"
Third call:   "a\\_b"  → "a\\\\_b"
```

## Reproduction

```python
def escape_md(text):
    for ch in ['_', '*', '`', '[', ']']:
        text = text.replace(ch, f'\\{ch}')
    return text

once  = escape_md("param_name")   # 'param\\_name'
twice = escape_md(once)            # 'param\\\\_name'
```

## Impact

- **Silent data corruption** — parameter names/descriptions with `_`, `*`, `` ` ``, `[`, `]` corrupted on every re-render
- **User-facing** — affects Telegram, Slack, and Email bot users in multi-parameter workflows
- **Cumulative** — each re-render doubles backslashes: `a_b` → `a\_b` → `a\\_b` → `a\\\\_b`

## Proposed Fix

Use regex with negative lookbehind to skip already-escaped characters:

```python
import re

def escape_md(text: str) -> str:
    if not isinstance(text, str):
        text = str(text)
    return re.sub(r'(?<!\\)([_*`\[\]])', r'\\\1', text)
```

Idempotent:
- `escape_md("a_b")` → `"a\_b"` ✓
- `escape_md("a\_b")` → `"a\_b"` (unchanged) ✓
- `escape_md(escape_md("a_b"))` == `escape_md("a_b")` ✓

## How This Was Found

Property-based testing with [Hypothesis](https://hypothesis.readthedocs.io/):

```python
@given(st.text(min_size=0, max_size=100))
@example("a_b")
@example("a*b")
def test_idempotence(text):
    once  = escape_md(text)
    twice = escape_md(once)
    assert twice == once  # FAILS
```
