## Summary

`BubbleLayoutAlgorithm::GetP2` computes the fillet point of the popup/tips
arrow. The only caller, `CalculateArrowPoint`, always passes
`ARROW_RADIUS = 2.0_vp`. JS accepts any `arrowWidth` / `arrowHeight` with
`Value() > 0` (not `%`). There is no `|r| < |side|` guard before `asin`:

```cpp
auto side = w1 / std::cos(theta);           // hypot(W/2, H-r)
auto alpha = std::asin(radius.ConvertToPx() / side);  // NaN if |r| ≥ |side|
```

`(W,H)=(1,1)` px, `r=2` px → `side ≈ 1.118 < 2` → `asin` **NaN** in
`defaultP2Height_`, `defaultP2Width_`, `typeTwoBeta_`. `BuildTopLinePath`
writes those into `ArcTo` / `LineTo` → `"nan"` in the clip path. Defaults
`16×8 vp` are fine. Same class as DataPanel `GetPaintPath` (`DTS2026073116282`).
Confirmed and fixed under `DTS2026090922585`.

## Contract

Every JS-reachable `arrowWidth > 0`, `arrowHeight > 0` with production
`ARROW_RADIUS = 2.0_vp` must yield finite `defaultP2Height_`,
`defaultP2Width_`, and `typeTwoBeta_`. `asin(r/side)` and `r/tan(asin(...))`
need **`|r| < |side|`**. Do not clamp `asin` to ±1: `|r/side|=1` → `α=π/2` →
`tan` blows up. Match the existing `W=0` early-return (leave header defaults).

## Vulnerable Code

`frameworks/core/components_ng/pattern/bubble/bubble_layout_algorithm.cpp`
`GetP2` (~183–196):

```cpp
CHECK_EQUAL_VOID(w1, 0);                    // only W=0
auto theta = std::atan(h1 / w1);
auto side = w1 /std::cos(theta);
auto alpha = std::asin(radius.ConvertToPx() / side);   // no |r|<|side| guard
```

## Minimal Counterexample

```cpp
// arrowWidth=1px, arrowHeight=1px, r=2px (production ARROW_RADIUS at 1x)
// Expected: finite P2 / beta (or early-return leaving header defaults)
// Actual:   all three NaN
```

JS: `bindPopup(..., { arrowWidth: 1, arrowHeight: 1 })`.

## How PBT Detected This

Harness: `pbt-native/bubble_getp2_pbt_test.cpp` (`extract_getp2.py` copies
production `GetP2`). Oracle: finite outputs on JS `(W,H)>0` with `r=2`.

| Property / regression | Result |
|---|---|
| `HeaderKatDefaultArrow` / `FilletDefined` properties | PASS |
| `ProductionRadiusFinite` | FAIL |
| `TinyArrowWidthHeightNan` (`W=H=1`, `r=2`) | FAIL |

## Suggested Fix

Guard **before** `asin`; do not clamp the argument to ±1:

```cpp
auto rPx = radius.ConvertToPx();
if (!std::isfinite(side) || std::fabs(side) <= std::fabs(rPx)) {
    return;
}
```
