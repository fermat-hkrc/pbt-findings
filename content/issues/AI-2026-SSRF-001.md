## Summary

`validate_plugin_url` is the sole SSRF guard for all user-supplied plugin URLs. It correctly blocks cloud metadata endpoints (`169.254.x.x`, `metadata.google.internal`) but does not block loopback addresses or alternative IP encodings. An authenticated user with plugin creation or update access can supply a URL pointing to `localhost` and use the backend as a proxy to reach any service on the host.

## Affected Call Sites

Every path accepting a user-supplied plugin URL delegates to `validate_plugin_url` as its only SSRF check:

| File | Line | Context |
|------|------|---------|
| `schemas/plugin.py` | 94 | Pydantic field validator — `PluginCreate.url` |
| `schemas/plugin.py` | 220 | Pydantic field validator — `PluginInfo.url` |
| `core/manager/plugin.py` | 329 | `_validate_network_url` — MCP SSE / HTTP transports |
| `core/manager/plugin.py` | 353 | `_validate_openapi_paths` — OpenAPI spec URLs |
| `core/manager/plugin.py` | 654 | `plugin_create` |
| `core/manager/plugin.py` | 871 | `plugin_update` |

## Confirmed Bypasses

All of the following pass `validate_plugin_url` without raising:

```
http://localhost/          # resolves to ::1 — loopback, not link-local
http://127.0.0.1/          # is_loopback=True, only is_link_local is checked
http://127.0.0.2/          # entire 127.0.0.0/8 range unblocked
http://0.0.0.0/            # unspecified — not loopback, not link-local
http://0/                  # resolves to 0.0.0.0
http://[::1]/              # IPv6 loopback — is_loopback=True, is_link_local=False
http://2130706433/         # decimal encoding of 127.0.0.1 — gaierror swallowed
http://0x7f000001/         # hex encoding of 127.0.0.1 — gaierror swallowed
http://0177.0.0.1/         # octal encoding — gaierror swallowed
```

## Root Cause

Two independent gaps in `url_validator.py`:

### Gap 1 — Only checks `is_link_local`, ignores `is_loopback` and `is_unspecified`

```python
def _is_cloud_metadata_address(ip_str: str) -> bool:
    addr = ipaddress.ip_address(ip_str)
    if isinstance(addr, ipaddress.IPv4Address):
        return addr.is_link_local or str(addr) == "100.100.100.200"
```

`127.0.0.1.is_loopback = True`, `127.0.0.1.is_link_local = False` → passes.
`0.0.0.0.is_loopback = False`, `0.0.0.0.is_link_local = False` → passes.
`::1.is_loopback = True`, `::1.is_link_local = False` → passes.

### Gap 2 — `socket.gaierror` silently swallowed, allowing non-DNS-resolvable encodings through

```python
except socket.gaierror:
    logger.warning(f"DNS resolution failed for hostname: {hostname}")
    # execution continues — URL accepted
```

`urlparse("http://2130706433/").hostname` returns `"2130706433"`. `socket.getaddrinfo("2130706433", None)` raises `gaierror`. Exception is caught and ignored — decimal-encoded loopback passes.

## Attack Scenario

Authenticated user creates a plugin with:

```json
POST /api/v1/plugins
{
  "name": "exfil",
  "url": "http://localhost:8000/api/v1/admin/users"
}
```

`validate_plugin_url` returns the URL unchanged. Plugin stored. When executed, the backend makes an outbound HTTP request to its own API with backend process credentials, bypassing authentication. Same technique reaches any service bound to `127.0.0.1` or `0.0.0.0`: internal databases, Redis, admin interfaces, cloud metadata endpoints on non-standard addresses.

## How This Was Found

Property-based testing with [Hypothesis](https://hypothesis.readthedocs.io/). The test `test_dangerous_urls_rejected` generates URLs from a `dangerous_hostnames` list and asserts every one raises `ValueError`. Fails for 6 of 9 hostnames: `localhost`, `127.0.0.1`, `0.0.0.0`, `0`, `2130706433`, `0x7f000001`.

```python
@given(scheme=st.sampled_from(["http", "https"]),
       hostname=dangerous_hostnames,
       port=st.integers(min_value=1, max_value=65535),
       path=paths)
def test_dangerous_urls_rejected(self, scheme, hostname, port, path):
    url = _make_url(scheme, hostname, port, path)
    try:
        result = validate_plugin_url(url)
        assert False, f"SSRF BYPASS: {url!r} passed as {result!r}"
    except (ValueError, socket.gaierror):
        pass
```

## Proposed Fix

### Fix Gap 1 — extend to cover all non-routable classes

```python
def _is_blocked_address(ip_str: str) -> bool:
    try:
        addr = ipaddress.ip_address(ip_str)
        return (
            addr.is_loopback        # 127.0.0.0/8, ::1
            or addr.is_link_local   # 169.254.0.0/16, fe80::/10
            or addr.is_unspecified  # 0.0.0.0, ::
            or str(addr) == "100.100.100.200"
            or (isinstance(addr, ipaddress.IPv6Address)
                and str(addr).startswith("fd00:ec2"))
        )
    except ValueError:
        return False
```

### Fix Gap 2 — parse alternative IP representations before DNS resolution

```python
def _parse_ip_permissive(hostname: str):
    """Parse hostname as an IP in decimal, hex, or octal encoding."""
    try:
        return ipaddress.ip_address(hostname)
    except ValueError:
        pass
    try:                          # decimal integer: 2130706433
        n = int(hostname)
        if 0 <= n <= 0xFFFFFFFF:
            return ipaddress.IPv4Address(n)
    except ValueError:
        pass
    try:                          # hex: 0x7f000001
        n = int(hostname, 16)
        if 0 <= n <= 0xFFFFFFFF:
            return ipaddress.IPv4Address(n)
    except ValueError:
        pass
    return None
```

In `validate_plugin_url`, before DNS resolution:

```python
direct_ip = _parse_ip_permissive(hostname)
if direct_ip is not None and _is_blocked_address(str(direct_ip)):
    raise ValueError(f"URL resolves to a blocked address: {direct_ip}")
```
