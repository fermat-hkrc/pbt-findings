## Summary

`MaskIpMiddle` is the helper that `ToAnonymousIp(input, true)` delegates to
for the production log path. It finds the first and last occurrence of the
delimiter and masks every character between them. For IPv6 addresses written
with `::` compression, the only colons in the string are the adjacent pair,
so `find(':')` and `rfind(':')` point at two consecutive indices. The loop
body then iterates at most once, encounters a `':'` which it skips, and
returns the string **unchanged** — the full IPv6 address is written to system
logs unmasked.

Addresses with three or more colons (e.g. `2001:db8::1`) mask correctly; the
bug is specific to addresses whose only colons are the adjacent `::` pair.

## Contract

`CommonUtils::ToAnonymousIp(input, /*maskMiddle=*/true)` must return a string
that differs from the input for any valid IP address. The `maskMiddle=true`
path is the production log path; its guarantee is that IP addresses are never
written to logs in full.

## Vulnerable Code

`utils/common_utils/src/netmanager_base_common_utils.cpp`, lines 385–395:

```cpp
std::string MaskIpMiddle(std::string &maskedResult, const std::string &delimiter)
{
    size_t start = maskedResult.find(delimiter);   // first ':'
    size_t end   = maskedResult.rfind(delimiter);  // last  ':'
    for (size_t i = start; i < end; i++) {         // ← collapses for '::'
        if (maskedResult[i] != delimiter[0] && maskedResult[i] != '/') {
            maskedResult[i] = '*';
        }
    }
    return maskedResult;
}
```

When `start` and `end` are adjacent (`end == start + 1` for `::`), the loop
range is a single index holding `':'`, which the guard skips. Nothing is
masked.

## Root Cause

`find` and `rfind` collapse to adjacent indices whenever the only delimiter
occurrences are the two characters of `::`. The loop guard `i < end` then
provides at most one iteration, and that iteration hits the `':'` skip
condition. The function was designed for addresses that have multiple
non-adjacent delimiters; it was never hardened against the `::` compressed
form.

## Shrunk Witnesses

| Input | `ToAnonymousIp(ip, true)` | Expected |
|---|---|---|
| `fe80::1` | `fe80::1` ❌ (unchanged) | masked |
| `::1` (loopback) | `::1` ❌ (unchanged) | masked |
| `2001::1` | `2001::1` ❌ (unchanged) | masked |

| Caller | What leaks |

Link-local (`fe80::...`), loopback (`::1`), and abbreviated global addresses
are written to system logs in full instead of masked.

## How PBT Detected This

A RapidCheck property generated random IPv6 strings (including compressed
forms) and asserted that `ToAnonymousIp(ip, true) != ip` for any valid IP.
The compressed `::` forms were the immediate falsifying inputs; RapidCheck
shrunk to the three minimal witnesses above.

The dedicated `BugDocs` regression test pins the requirement explicitly:

```cpp
TEST(ToAnonymousIpPBT_BugDocs, MaskMiddle_ChangesCompressedIpv6)
{
    const std::vector<std::string> leaking = {
        "fe80::1",
        "::1",
        "2001::1",
    };
    for (const std::string &ip : leaking) {
        std::string masked = CommonUtils::ToAnonymousIp(ip, /*maskMiddle=*/true);
        EXPECT_NE(masked, ip)
            << "ToAnonymousIp(\"" << ip << "\", true) returned the input "
            << "unchanged — full IPv6 address leaked to logs unmasked";
    }
}
```

Result on an unfixed branch:

## Suggested Fix

Guard the collapsed-range case explicitly so that something is always masked
when the input contains a delimiter:

```cpp
std::string MaskIpMiddle(std::string &maskedResult, const std::string &delimiter)
{
    size_t start = maskedResult.find(delimiter);
    size_t end   = maskedResult.rfind(delimiter);
    // Collapsed range: the only delimiters are the adjacent '::' pair.
    // end == start + 1, so the normal loop masks nothing. Fall back to
    // masking everything after the first delimiter group.
    if (start == std::string::npos || end <= start + delimiter.size()) {
        size_t firstDelim = maskedResult.find(delimiter);
        for (size_t i = firstDelim + delimiter.size(); i < maskedResult.size(); i++) {
            if (maskedResult[i] != delimiter[0] && maskedResult[i] != '/') {
                maskedResult[i] = '*';
            }
        }
        return maskedResult;
    }
    for (size_t i = start; i < end; i++) {
        if (maskedResult[i] != delimiter[0] && maskedResult[i] != '/') {
            maskedResult[i] = '*';
        }
    }
    return maskedResult;
}
```

Alternatively, expand the IPv6 string to its full 8-group form before masking
so that `::` is eliminated and `find`/`rfind` always differ by several groups.

## Impact

PII leak on the production log path. Compressed IPv6 addresses — including
link-local (`fe80::...`) and loopback (`::1`) — are written to system logs
unmasked. Four separate callers in the networking service layer are affected.
There is no crash or error signal; the leak is silent.
