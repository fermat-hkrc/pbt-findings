## Summary

After a real translate, the covering arm sets
`totalMainSize_ = prevPos - spaceWidth_`. `prevPos` is the **line-packing
cursor**; it only advances on lane end. A partial last line leaves it at the
previous full line’s end. Items translate correctly; scroll range is one line
short.

**Confirmed and fixed** under `DTS2609150123188`.

## Contract

Last cached item covering the list ⇒ `totalMainSize_ == last.endPos`.
Same as `UpdateTotalMainSize` and the `it == end` covering branch.

## Vulnerable Code

```cpp
if (prevIndex >= totalItemCount_ - 1) {
    totalMainSize_ = prevPos - spaceWidth_;   // line cursor, not last item
}
```

## Minimal Counterexample

`lanes=2`, total 5, last `endPos=320` → `totalMainSize_=210` (expected 320).

## How PBT Detected This

`LastCoveringItemSetsTotalToEndPos` / `AgreesWithUpdateTotalMainSize` FAIL.

## Suggested Fix

`totalMainSize_ = posMap_.rbegin()->second.endPos;`
