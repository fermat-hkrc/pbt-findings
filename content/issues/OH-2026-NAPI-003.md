## Summary

`NativeCallbackScopeManager::Open` only increments `asyncCallbackScopeDepth_`
when allocation succeeds. `Close` still does `asyncCallbackScopeDepth_--`
even when `scope == nullptr`. A failed open paired with cleanup therefore
underflows `size_t` from `0` to `SIZE_MAX`, permanently desynchronizing the
depth counter used by `MakeCallback` (`depth == 0` special-case). Confirmed
and fixed under `DTS2026081440197`.

## Vulnerable Code

`callback_scope_manager/native_callback_scope_manager.cpp`
`NativeCallbackScopeManager::Close`:

```cpp
void NativeCallbackScopeManager::Close(NativeCallbackScope* scope)
{
    if (scope != nullptr) {
        delete scope;
    }
    asyncCallbackScopeDepth_--;   // unconditional — runs for nullptr too
}
```

`Open` only `++`s on non-null success. Live pairing from
`InternalMakeCallback` when `asyncContext == nullptr` and `Open` fails still
reaches `CloseScope` → `Close(nullptr)`.

## Contract

- After `Open` failure (returns `nullptr`), depth must be unchanged.
- `Close(nullptr)` must be a no-op on depth (mirrors success-only `++`).
- Unit tests assert open → depth+1 and close → depth restored.

## Minimal Counterexample

```cpp
NativeCallbackScopeManager mgr;
assert(mgr.GetAsyncCallbackScopeDepth() == 0);
mgr.Close(nullptr);
// Expected: depth stays 0
// Actual:   depth == SIZE_MAX
```

Harness: `pbt-native/callback_scope_manager_close_pbt_test.cpp` (links the

| `FailedOpenPairedCloseKeepsDepth` | FAIL |

## Impact

After one bad `Close(nullptr)`, depth is sticky `SIZE_MAX` for the life of
the manager/engine. Later `MakeCallback` never takes the
`rst == nullptr && depth == 0` path and may return a raw null `JSValueRef*`
instead of `Undefined`. Happy-path non-null open/close pairs are unaffected.
Not High: primary live trigger is OOM/`new (std::nothrow)` failure or a
caller pairing `Close(nullptr)` with a failed open.

## Suggested Fix

Only decrement when a real scope was closed:

```cpp
void NativeCallbackScopeManager::Close(NativeCallbackScope* scope)
{
    if (scope != nullptr) {
        delete scope;
        if (asyncCallbackScopeDepth_ > 0) {
            asyncCallbackScopeDepth_--;
        }
    }
}
```
