## Summary

`FindEndIdx` walks `gridMatrix_` backward for the last **origin** cell.
The scan uses `val > 0`, so item 0 is never selected. Miss path returns
hardcoded `{0,0,0}` instead of `EndIndexInfo` default `{-1,-1,-1}`.

**Confirmed** under `DTS2026091425514` (accepted; **not fixed yet**).

## Contract

Origin cells are `val >= 0`. Last origin at or above `endLine` with real
`(y, x)`. No origin → `{}` (`{-1,-1,-1}`), same as a missing line.
`FindStartIdx` already treats `val == 0` as item 0.

## Vulnerable Code

```cpp
if (val > 0 && val > maxIdx) { ... }   // item 0 never wins
if (maxIdx > 0) { return {maxIdx, y, maxCol}; }
return {0, 0, 0};   // invents item 0 at origin
```

## Minimal Counterexample

`{0:{1:0}}` → `{0,0,0}` (expected `{0,0,1}`). Continuation-only `{0:{0:-1}}`
→ `{0,0,0}` (expected `{-1,-1,-1}`).

## How PBT Detected This

`ItemZeroRecordsPosition` / `OnlyContinuationsReturnSentinel` FAIL.

## Suggested Fix

`val >= 0` / `maxIdx >= 0`; miss → `return {}`.
