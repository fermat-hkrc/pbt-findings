## Summary

`StrSafeCopy(dst, len, src)` treats `len` as destination capacity (room for
chars + NUL). The copy loop already stops at `i + 1 < len`, but the terminator
is unconditional. When `len == 0` the loop is skipped and `i` stays `0`, so
`dst[i] = '\0'` writes `dst[0]` — one byte outside a zero-capacity buffer.

The `src == NULL` early path has the same hole: `dst[0] = '\0'` with no `len`
check. Two identical definitions (HAL common + HDI twin) share the bug.

Not High: grepped in-tree callers pass `sizeof(tempSsid)` (`> 0`). Latent
footgun on the helper surface, not a proven hot path.

Confirmed and fixed under `DTS2026072818599`.

## Vulnerable Code

`wifi/relation_services/common/wifi_hal_common_func.c` — `StrSafeCopy` (~29).
Twin, same body: `wifi_hdi_common.c` (~845).

```c
void StrSafeCopy(char *dst, unsigned len, const char *src)
{
    if (dst == NULL) {
        return;
    }
    if (src == NULL) {
        dst[0] = '\0';   // also OOB if len == 0
        return;
    }
    unsigned i = 0;
    while (i + 1 < len && src[i] != '\0') {
        dst[i] = src[i];
        ++i;
    }
    dst[i] = '\0';       // len == 0 → i == 0 → write outside capacity
}
```

## Trigger Conditions

1. Non-null `dst`, `len == 0`, any `src` (including a non-null string) — one-byte
   write at `dst[0]`.
2. Non-null `dst`, `src == NULL`, `len == 0` — same write on the early clear.
3. `len >= 1` — payload and terminator stay inside `dst[0 .. len)`. Fine.

`len == 0` must be a no-op (or a documented error). The name “safe copy” plus
the `i + 1 < len` payload bound already imply the terminator obeys the same
capacity.

## Impact

- One-byte OOB write if a caller ever passes zero capacity with a true
  zero-size or end-of-object pointer.
- Current call sites (`wifi_hdi_wpa_callback.cpp` ~690, ~723) use
  `sizeof(tempSsid)` — bounded, not this bug.
- Medium: public HAL helper, two copies, contract violation, no demonstrated
  field crash.

## Minimal Counterexample

```c
char cell = 'Z';
StrSafeCopy(&cell, 0, "abc");
// before: cell == '\0'  (wrote dst[0] with zero capacity)
// after:  cell == 'Z'   (no write)
```

## Suggested Fix

Guard zero capacity before any store. Same change on both `.c` copies:

```c
void StrSafeCopy(char *dst, unsigned len, const char *src)
{
    if (dst == NULL || len == 0) {
        return;
    }
    if (src == NULL) {
        dst[0] = '\0';
        return;
    }
    unsigned i = 0;
    while (i + 1 < len && src[i] != '\0') {
        dst[i] = src[i];
        ++i;
    }
    dst[i] = '\0';
}
```
