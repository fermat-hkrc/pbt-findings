## Summary

Level-3 colon form `(max-height: 800px)` is the documented Syntax example.
`CSS_LEVEL3_RULE` unit group is `dpi|dppx|dpcm|vp` — **`px` missing**. Level-4
already lists `px`. Trailing `px` → SYNTAX → `matches=false`. Omitting the
unit or using `(height<=800px)` works.

**Confirmed** under `DTS2026091412083` (accepted; **not fixed yet**).

## Contract

`(max-height:n px)` ≡ `h <= n` ≡ no-unit `(max-height:n)`. Syntax NOTE: vp and
px are supported on numeric features.

## Vulnerable Code

```cpp
// CSS_LEVEL3_RULE — px absent
"\\((min|max)-([a-z-]+):([\\d\\.]+)(dpi|dppx|dpcm|vp)?\\)"
```

## Minimal Counterexample

height=400, `(max-height:800px)` → false (expected true).

## How PBT Detected This

`KatMaxHeight800px` / `MinMaxPxUnit` FAIL; no-unit and Level-4 `px` PASS.

## Suggested Fix

Add `px` to the Level-3 unit group, same order as Level-4.
