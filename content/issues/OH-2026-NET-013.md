## Summary

`CommonUtils::ExtractDomainFormUrl` slices the URL after `"//"` and stops
only at `'/'`. A URL with `:port` — valid HTTP — therefore keeps the port in
the extracted "domain", which is then passed as the **node** argument to
`getaddrinfo_ext(domain.c_str(), nullptr, …)` (`net_dns_resolve.cpp:75`).
DNS resolution fails for a valid probe URL with a non-default port, and the
twin `NetHttpProbe::SetResolveOption` assembles `domain + ":" + port + ":" +
ip` → `example.com:8080:80:ip`, a malformed `CURLOPT_RESOLVE` entry.

Default connectivity-check URLs
(`http://connectivitycheck.platform.hicloud.com/generate_204`) carry no port,
which masks the bug. No crash / UB.

Confirmed and fixed under `DTS2026091437628` (`465cf241b` "fix
ExtractDomainFormUrl with host:port": strip `:port` after the `/` slice,
skipping bracketed IPv6 hosts).

## Vulnerable Code

`utils/common_utils/src/netmanager_base_common_utils.cpp` (~1080–1100):

```cpp
size_t domainStartPos = doubleSlashPos + 2;
size_t domainEndPos = url.find('/', domainStartPos);  // ':' is not a terminator
if (domainEndPos != std::string::npos) {
    domain = url.substr(domainStartPos, domainEndPos - domainStartPos);
} else {
    domain = url.substr(domainStartPos);
}
return domain;   // "example.com:8080" survives
```

## Trigger Conditions

Any dual-stack probe URL with a non-default port
(`NetMonitor::StartDualStackProbeThread` → `ExtractDomainFormUrl(httpUrl_)`).
Port-less and bare-host URLs are unaffected.

## Impact

Medium — silent wrong result: the dual-stack probe DNS resolution misses for
valid URLs; no crash.

## Minimal Counterexample

```
ExtractDomainFormUrl("https://example.com:8080/path")  // "example.com:8080", want "example.com"
ExtractDomainFormUrl("http://a:0/")                    // "a:0", want "a"
ExtractDomainFormUrl("http://example.com/path")        // "example.com" (OK)
```

## How PBT Detected This

`pbt-native/extract_domain_form_url_pbt_test.cpp` (real
`netmanager_base_common_utils.cpp`), property `PortStrippedForDns`:

```
∀ scheme, host, port, path.
  ExtractDomainFormUrl(scheme + "://" + host + ":" + port + "/" + path) == host
```

Shrunk witness `http://a:0/`; `RegressionPortIncluded` reconfirmed serially
(`PBT_TEST_JOBS=1`). No-port KATs passed, hiding the port branch.

## Suggested Fix

After the existing `/` slice, drop `:port` on a non-bracket host (skip `'['`
so IPv6 literals such as `[::1]` are not truncated) — as landed in
`465cf241b`:

```diff
     } else {
         domain = url.substr(domainStartPos);
     }
+    if (!domain.empty() && domain.front() != '[') {
+        size_t colonPos = domain.find(':');
+        if (colonPos != std::string::npos) {
+            domain.resize(colonPos);
+        }
+    }
     return domain;
```

Sibling `GetHostnameFromURL05` already strips `:port`; do **not** copy its
raw `find(':')` — that truncates `http://[::1]/` to `"["`.
