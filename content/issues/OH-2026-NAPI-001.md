## Summary

`RuntimeType::IsType` treats `strcmp` non-zero (names **differ**) as a match.
Unrelated `DECL_TYPE` classes therefore succeed `DynamicCast`; the identity
cast `TypeBase → TypeBase` is the only reachable `nullptr`. Documented
purpose is “safe dynamic cast” (`ffi_remote_data.h`). Confirmed and fixed
under `DTS2026081506434`.

## Vulnerable Code

`runtimetype.h` `RuntimeType::IsType`:

```cpp
if (strcmp(this->GetTypeName(), target->GetTypeName())) {
    return true;  // non-zero ⇒ names differ
}
```

Correct: `== 0` then return true, else walk parents.

## Impact

`RemoteData::Create<T>(id)` / `FFIData::GetData<T>` can return a registered
object of the wrong concrete class as `T*`. Medium: needs id-reuse under a
different class than requested.
