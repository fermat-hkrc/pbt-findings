## Summary

`ToAnonymousIp` redacts only if a classifier regex matches; otherwise it
returns `input`. IPv6 CIDR must hit `IPV6_MASK_PATTERN`. The prefix suffix
was `1[0-2][0-8]|[1-9]\d|[1-9]` — 1–128 **except 0, 109, and 119**
(`1[0-2][0-8]` last digit is 0–8). Unmatched CIDR falls through unredacted.

Live logs pass `addr/prefix`: `Network::UpdateRoutes` builds
`address_ + "/" + prefixlen_`; `NetsysNativeService::NetworkAddRoute` logs
`ToAnonymousIp(destination)` on `%{public}s`. IPv6 default is prefix **0**
(`Route::IsIpv6Default`). `/64` redacted; `/0` did not.

Sibling `IP_MASK_PATTERN` already includes IPv4 `/0`. Same-file
`MAX_IPV6_PREFIX_LENGTH` is 128. Distinct from the compressed-`::` leak
(`OH-2026-NET-001` / `DTS2026062926934`).

Confirmed and fixed under `DTS2026090525146` (`f3c54b9da`: prefix
`12[0-8]|1[01]\d|[1-9]\d|\d`).

## Vulnerable Code

`utils/common_utils/src/netmanager_base_common_utils.cpp` `IPV6_MASK_PATTERN`:

```cpp
const std::regex IPV6_MASK_PATTERN{
    "([\\da-fA-F]{0,4}:){2,7}([\\da-fA-F]{0,4})/(1[0-2][0-8]|[1-9]\\d|[1-9])"};
```

`ToAnonymousIp` then:

```cpp
if (std::regex_match(maskedResult, IPV6_PATTERN) ||
    std::regex_match(maskedResult, IPV6_MASK_PATTERN)) {
    return MaskIpv6(maskedResult);
}
return input;
```

`MaskIpv6` already stops at `/` and keeps the suffix; the classifier was the
bug.

## Trigger Conditions

Any IPv6 dest logged as `addr/0` (default route), `/109`, or `/119`. No
special configuration. `/64` and IPv4 `0.0.0.0/0` were already redacted.

## Impact

Medium — full IPv6 on HiLog `%{public}s` for default-route `/0` (and regex
holes `/109`, `/119`). No crash / UB.

## Minimal Counterexample

```
ToAnonymousIp("2001:db8:1:2:3:4:5:6/64")   // contains * (control)
ToAnonymousIp("2001:db8:1:2:3:4:5:6/0")    // equals input
ToAnonymousIp("2001:db8:1:2:3:4:5:6/109")  // equals input
ToAnonymousIp("2001:db8:1:2:3:4:5:6/119")  // equals input
ToAnonymousIp("0.0.0.0/0")                 // redacted (IPv4 sibling)
```

## How PBT Detected This

`pbt-native/to_anonymous_ip_redact_pbt_test.cpp` `Ipv6CidrEveryPrefixRedacted`:

```
∀ POSIX IPv6 ip, p ∈ 0..128.
ToAnonymousIp(ip+"/"+p) ≠ cidr and contains *
```

Shrunk to `/119`; `/0` and `/109` fail the same regex.

## Suggested Fix

Same shape as sibling `IP_MASK_PATTERN` (longest alternative first, `\d`
includes 0), for 0–128:

```cpp
const std::regex IPV6_MASK_PATTERN{
    "([\\da-fA-F]{0,4}:){2,7}([\\da-fA-F]{0,4})/(12[0-8]|1[01]\\d|[1-9]\\d|\\d)"};
```

`/129` still fails. `MaskIpv6` unchanged.
