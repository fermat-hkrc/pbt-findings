## Summary

Static `GetOptionalTaggedValue` compares the optional leading tag byte with
**no empty check**. On an empty cursor under `NDEBUG`, `sp[0]` is an OOB read
before the tag compare; if garbage matches the tag, payload `Read` escalates.

Dynamic sibling fail-closes first:
`if (UNLIKELY(sp.Size() == 0U)) return novalue;`. Confirmed and fixed under
`DTS2026080810367` (internal system).

## Vulnerable Code

`static_core/libarkfile/helpers.h`:

```cpp
template <class T, class E>
inline std::optional<T> GetOptionalTaggedValue(Span<const uint8_t> sp, E tag,
                                               Span<const uint8_t> *next)
{
    if (sp[0] == static_cast<uint8_t>(tag)) {   // no Size()==0 guard
        sp = sp.SubSpan(1);
        T value = static_cast<T>(Read<sizeof(T)>(&sp));
        *next = sp;
        return value;
    }
    *next = sp;
    std::optional<T> novalue = {};
    return novalue;
}
```

## Contract

1. Empty optional-tagged region → empty optional, **no** byte read.
2. Must not index `sp[0]` unless `sp.Size() > 0`.
3. In-tree reference: dynamic `GetOptionalTaggedValue`.

## Minimal Counterexample

```cpp
Span<const uint8_t> empty(/*data*/ nullptr, 0U);
Span<const uint8_t> next;
auto v = GetOptionalTaggedValue<uint32_t>(empty, tag, &next);
// Expected: !v.has_value(); no byte read
// Actual (NDEBUG): OOB read of sp[0]
```

## How PBT Detected This

Harness: `pbt-native/optional_tagged_value_pbt_test.cpp`.

| Property | Result (unfixed SUT) |
|---|---|
| Present tag + payload | PASS |
| Empty span returns nullopt without OOB | FAIL |

## Impact

| Axis | Rating |
|------|--------|
| Impact when hit | OOB **read** of one byte; optional escalate via `Read` |
| Likelihood on well-formed abc | Low |
| Likelihood on truncated / crafted abc | Medium |
| Overall | **Medium** |

Callers: static method/class optional tagged fields (`CODE`, `SOURCE_LANG`,
`DEBUG_INFO`, `SOURCE_FILE`, …).

## Suggested Fix

Match libpandafile:

```cpp
std::optional<T> novalue = {};
if (UNLIKELY(sp.Size() == 0U)) {
    return novalue;
}
if (sp[0] == static_cast<uint8_t>(tag)) {
    ...
}
```
