## Summary

Static `EnumerateTaggedValues` / `EnumerateTaggedValuesWithEarlyStop` loop while
the current byte equals `tag`, but never test that the span still has a byte.
On an empty span under `NDEBUG`, `sp[0]` is an OOB read; if garbage matches the
tag, the loop body calls `Read` / `SubSpan` and can poison the cursor.

Dynamic sibling stops cleanly:
`while (sp.Size() > 0U && sp[0] == static_cast<uint8_t>(tag))`. Confirmed and
fixed under `DTS2026080810178` (internal system).

## Vulnerable Code

`static_core/libarkfile/helpers.h` — both overloads:

```cpp
template <class T, class E, class Callback>
inline void EnumerateTaggedValues(Span<const uint8_t> sp, E tag, Callback cb,
                                  Span<const uint8_t> *next)
{
    while (sp[0] == static_cast<uint8_t>(tag)) {   // no Size() > 0
        sp = sp.SubSpan(1);
        T value(Read<sizeof(T)>(&sp));
        cb(value);
    }
    if (next != nullptr) {
        *next = sp;
    }
}
```

`Span::operator[]` is assert-only; `NDEBUG` removes the bound check.

## Contract

1. Must not index `sp[0]` when `sp.Size()==0`.
2. Empty span → stop enumeration (zero callbacks), optionally set `*next = sp`.
3. In-tree reference: dynamic `libpandafile` `EnumerateTaggedValues*`.

## Minimal Counterexample

```cpp
Span<const uint8_t> empty(/*data*/ nullptr, 0U);  // or any Size()==0 span
EnumerateTaggedValues<uint32_t>(empty, tag, [](auto) {}, nullptr);
// Expected: no callbacks, no byte read
// Actual (NDEBUG): OOB read of sp[0]
```

## How PBT Detected This

Harness: `pbt-native/enumerate_tagged_values_pbt_test.cpp`.

| Property | Result (unfixed SUT) |
|---|---|
| Non-empty tag-run round-trips | PASS |
| Empty span does not OOB / does not callback | FAIL |

## Impact

| Axis | Rating |
|------|--------|
| Impact when hit | OOB **read** of tag byte; optional further poison via `Read` |
| Likelihood on well-formed abc | Low |
| Likelihood on truncated / crafted abc | Medium |
| Overall | **Medium** |

Callers: static method/field/class annotation and related tagged-list walks.

## Suggested Fix

Match libpandafile:

```cpp
while (sp.Size() > 0U && sp[0] == static_cast<uint8_t>(tag)) {
    ...
}
```

Same gate on `EnumerateTaggedValuesWithEarlyStop`.
