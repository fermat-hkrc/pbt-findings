## Summary

`Point3` stores its components as floats (`scalar x_`, `y_`, `z_`), but its
scale operators cast back through integers — `static_cast<int64_t>(x_ * scale)`
in `operator*` / `operator*=`, and `static_cast<int>(x_ / divisor)` in
`operator/=`. That truncates the result toward zero, so any fractional product
or quotient silently loses precision. `p *= s` / `p * s` then produce
**wrong 3D coordinates** whenever the scale (or divisor) is not an integer, and
`p /= d` disagrees with the free `p / d` on the same type.

The de-facto contract is set by `PointF::operator*` (`point.h:179-186`), which
uses pure float products with **no** integer cast, and by `Point3::operator+`
/ `operator-`, which already do componentwise float math. Only `*`, `*=`, and
`/=` deviate — a PointI paste pattern (int64 is intentional on **integer**
`PointI`, not on float `Point3`).

Confirmed and fixed under `DTS2026071430826`.

## Vulnerable Code

`rosen/modules/2d_graphics/include/utils/point3.h` — **PointI-style integer
casts** on **float** storage:

| Operator | Buggy | Correct (match `PointF`) |
|----------|-------|--------------------------|
| `operator*` / `operator*=` | `static_cast<int64_t>(x_ * scale)` | `x_ * scale` |
| `operator/=` | `static_cast<int>(x_ / divisor)` | `x_ / divisor` |
| free `operator/` | `x_ / divisor` | (already correct) |

```cpp
// operator*=  — wrong for scalar float
x_ = static_cast<int64_t>(x_ * scale);

// free operator*
return Point3(static_cast<int64_t>(p.x_ * scale), ...);

// operator/=  — truncates; free operator/ does not
x_ = static_cast<int>(x_ / divisor);
```

The same header already had a fixed typo in `operator+`
(`fixed/point3_operator_plus_wrong_operands.md`).

## Trigger Conditions

1. Code constructs a `Point3` and scales or divides it by a non-integer scalar
   (or any value that leaves a fractional result): `p * 1.5f`, `p /= 2.0f`.
2. The `static_cast<int64_t>` / `static_cast<int>` truncates toward zero.
3. The stored coordinates are silently wrong, and `operator/=` no longer agrees
   with the free `operator/`.

## Impact

- **Silently wrong 3D coordinates** from scale/divide-assign whenever the
  operand is non-integer. No crash.
- `Point3` is passed into **DrawShadow** / NDK `OH_Drawing_CanvasDrawShadow`
  (`planeParams`, `devLightPos`). In-tree production paths mostly construct
  literals, but any app or binding doing `p * s` or `p /= d` on light/plane
  geometry gets truncated values.
- **Medium:** public Drawing API on shadow/light 3D parameters, wrong geometry
  without crash; same bug class as the fixed Point3 `operator+`. Not rated High
  — no in-tree `p * s` / `p /= d` in `rosen/` today.

## Minimal Counterexample

```
p = Point3(1.0, 2.0, 3.0)
q = p * 1.5
// Expected: (1.5, 3.0, 4.5)
// Actual:   (1.0, 3.0, 4.0)   ← int64_t truncation per component

r = Point3(3.0, 5.0, 7.0)
freeDiv = r / 2.0   → (1.5, 2.5, 3.5)
r /= 2.0            → (1.0, 2.0, 3.0)
// r.GetX() == freeDiv.GetX()  →  1 == 1.5  →  FALSE
```

```cpp
#include "utils/point3.h"
using namespace OHOS::Rosen::Drawing;

int main() {
    Point3 p(1.0f, 2.0f, 3.0f);
    Point3 q = p * 1.5f;
    assert(q.GetX() == 1.5f);  // FAILS: got 1.0
    assert(q.GetZ() == 4.5f);  // FAILS: got 4.0

    Point3 r(3.0f, 5.0f, 7.0f);
    r /= 2.0f;
    assert(r.GetX() == 1.5f);  // FAILS: got 1.0
}
```

## How PBT Detected This

`pbt-native/point3_scale_pbt_test.cpp` — `Point3ScalePBT`:

- `ScaleMatchesFloatProduct` — `(p * s).GetX() == p.GetX() * s` (and Y, Z)
- `ScaleAssignMatchesFloatProduct` — same for `*=`
- `FractionalScaleMustNotTruncate` — **FAIL** (witness `p = (1,2,3) * 1.5`)
- `DivideAssignMustMatchFreeDivide` — **FAIL** (`p /= 2.0f` ≠ `p / 2.0f`)

Detected by algebraic invariant: scaling a float `Point3` must preserve float
products. First failing inputs were fractional scales; RapidCheck shrunk to the
fixed witnesses above.

## Suggested Fix

Match `PointF` — store float products/quotients directly, drop the integer
casts:

```cpp
inline Point3& Point3::operator*=(scalar scale)
{
    x_ *= scale;
    y_ *= scale;
    z_ *= scale;
    return *this;
}

inline const Point3 operator*(const Point3& p, scalar scale)
{
    return Point3(p.x_ * scale, p.y_ * scale, p.z_ * scale);
}

inline Point3& Point3::operator/=(scalar divisor)
{
    if (divisor == 0) {
        return *this;
    }
    x_ /= divisor;
    y_ /= divisor;
    z_ /= divisor;
    return *this;
}
```
