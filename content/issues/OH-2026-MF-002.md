## Summary

`Format` move ctor/assign copy `shared_ptr<Meta> meta_` (`this->meta_ = rhs.meta_`)
instead of transferring it, while `formatVecMap_` is correctly `swap`ped.
After `Format dst(std::move(src))`, mutating the still-alive moved-from `src`
rewrites `dst` through the shared `Meta`. Copy ctor already deep-copies;
`SetMeta` deep-copies when `use_count > 1` “to avoid unintended aliasing.”

**Confirmed and fixed** under `DTS2026082129239`.

## Contract

Move must transfer unique ownership of `meta_` (leave moved-from non-aliasing).
Post-move mutation of the source must not rewrite the destination.

## Vulnerable Code

```cpp
Format::Format(Format &&rhs) noexcept
{
    this->meta_ = rhs.meta_;              // SHARE, not transfer
    std::swap(formatVecMap_, rhs.formatVecMap_);
}
```

## Minimal Counterexample

```cpp
Format src; src.PutIntValue("k", 0);
Format dst(std::move(src));
src.PutIntValue("k", 0x5a5a5a5a);
// dst.GetIntValue("k") == 0x5a5a5a5a  (expected 0)
```

## How PBT Detected This

`MovedFromMutationDoesNotAliasDest` / `MovedFromNewKeyDoesNotAppearOnDest` FAIL.
Transfer properties PASS.

## Suggested Fix

Move ctor: `meta_ = std::move(rhs.meta_); rhs.meta_ = std::make_shared<Meta>();`
Move assign: `std::swap(this->meta_, rhs.meta_);` (dest already has a Meta).
