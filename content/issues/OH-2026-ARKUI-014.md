## Summary

`CheckColorAlpha` packs compact `rgba(r,g,b,a)` unit-interval alpha. It casts
`a` to `uint8_t` **before** `* 0xff`, so every α in `[0, 1)` becomes 0.
SVG `stop-color` first parses via `FromRGBO` (correct `0.5 → 0x80`) then
overlays this and clobbers to fully transparent.

**Confirmed** under `DTS2026090920220` (accepted; **not fixed yet**).

## Contract

Accepted `rgba(r,g,b,a)` with `a ∈ [0, 1]` must pack the same 8-bit alpha as
`Color::FromRGBO(r, g, b, a)`.

## Vulnerable Code

```cpp
result = Color::FromARGB(static_cast<uint8_t>(std::min(MAX_ALPHA, alpha)) * 0xff, ...);
// uint8_t(0.5) * 255 → 0, not round(0.5*255)=128
```

## Minimal Counterexample

`"rgba(0,49,83,0.5)"` → `0x00003153` (expected `0x80003153`).

## How PBT Detected This

Differential vs `FromRGBO`: `AgreesWithFromRGBOOnUnitOpacity` FAIL.

## Suggested Fix

`result = Color::FromRGBO(red, green, blue, std::min(MAX_ALPHA, alpha));`
