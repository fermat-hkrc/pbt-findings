## Summary

`IsSizeSupportDma` is the DMA area gate. It must return false unless
`width * height` is a representable, non-negative area at or above
`DMA_SIZE` (512×512). The overflow check only covers **both-positive** sizes.
Mixed-sign and both-negative products skip it, then the signed multiply
wraps (or lands on `+262144`) and the function returns **true**. Callers
treat true as permission to use `DMA_ALLOC`.

**Confirmed and fixed** under `DTS2026082249247`.

## Contract

Same-file sibling `CheckMulOverflow(w, h, 1)` is the overflow oracle: if
that is true, the product is not an `int32` area and DMA must not be
selected. `IsValidImageInfo` rejects `width <= 0 || height <= 0`. A
non-positive extent is not DMA-eligible.

## Vulnerable Code

```cpp
bool ImageUtils::IsSizeSupportDma(const Size &size)
{
    if (size.width > 0 && size.height > INT_MAX / size.width) {
        return false;
    }
    return size.width * size.height >= DMA_SIZE;
}
```

The `if` never runs when `width <= 0`. Then `width * height` is a signed
multiply of values the function has not proven in-range.

## Minimal Counterexample

```cpp
ImageUtils::IsSizeSupportDma({262144, -46341});  // expected false, actual true
ImageUtils::IsSizeSupportDma({-512, -512});      // expected false, actual true
```

Positive in-range `{512, 512}` still true. `{512, INT_MAX}` still false
(the existing both-positive arm).

## How PBT Detected This

`pbt-native/is_size_support_dma_pbt_test.cpp`

Oracle: `CheckMulOverflow(w,h,1)` ⇒ not DMA; any non-positive extent ⇒ not DMA.

| Case | Result |
|---|---|
| Mixed-sign overflow wrap | FAIL (true) |
| Both-negative min area | FAIL (true) |
| Both-positive overflow `{512, INT_MAX}` | PASS (false) |

## Suggested Fix

Reject non-positive extents and use the sibling overflow helper:

```diff
 bool ImageUtils::IsSizeSupportDma(const Size &size)
 {
-    if (size.width > 0 && size.height > INT_MAX / size.width) {
+    if (size.width <= 0 || size.height <= 0) {
+        return false;
+    }
+    if (CheckMulOverflow(size.width, size.height, 1)) {
         return false;
     }
     return size.width * size.height >= DMA_SIZE;
 }
```
