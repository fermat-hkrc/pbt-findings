## Summary

`GridLayoutInfo::GetIrregularHeight` estimates total lines as
`(lastKnownLine + 1) / itemRatio` where
`itemRatio = (FindEndIdx(lastKnownLine).itemIdx + 1) / childrenCount`. When the
line is missing from `gridMatrix_`, `FindEndIdx` returns `{}` with
`itemIdx = -1` → ratio `0` → **`/ 0` → `+inf`** content height.

High: infinite scrollbar / scroll extent on irregular Grid during partial
layout. Confirmed and fixed by developers (`DTS2026072325132`).

## Vulnerable Code

`frameworks/core/components_ng/pattern/grid/grid_layout_info.cpp` —
`GetIrregularHeight` (~513), `FindEndIdx` (~897):

```cpp
// ~522
float itemRatio = static_cast<float>(FindEndIdx(lastKnownLine).itemIdx + 1)
                / static_cast<float>(childrenCount);
// FindEndIdx missing line → {} → itemIdx=-1 → itemRatio=0
float estTotalLines = std::round(static_cast<float>(lastKnownLine + 1) / itemRatio); // /0 → +inf
```

Root cause: no guard when `itemIdx == -1` (missing line) before dividing by
`itemRatio`.

## Trigger Conditions

1. Irregular Grid with `childrenCount_ > 0` and some `lineHeightMap_` entries.
2. `lastKnownLine` is **not** in `gridMatrix_` (partial layout: heights present
   past filled matrix, or matrix cleared while `lineHeightMap_` remains).
3. `FindEndIdx` → `itemIdx = -1` → `itemRatio = 0` → estimate divides by zero.

## Impact

- `GridPattern::GetTotalHeight` / `UpdateScrollBarOffset` and irregular
  `GetContentHeight` feed **infinite** extent → broken scrollbar, overscroll,
  jump-to-end.
- Common during partial layout on irregular Grid.
- High: wrong scroll geometry on a live UI path, not just a latent math edge.

## Minimal Counterexample

```
childrenCount_ = 100
lineHeightMap_ = {0: 50, 5: 50}
gridMatrix_    = {}          // lastKnownLine=5 not in matrix
mainGap        = 10

GetIrregularHeight(10) → +inf
// expected: finite (known height only, or guarded estimate)
```

## Suggested Fix

```cpp
auto endInfo = FindEndIdx(lastKnownLine);
if (endInfo.itemIdx < 0) {
    return synced_ ? avgLineHeight_ * knownLineCnt
                   : GetTotalLineHeight(0.0f);  // known only; no estimate
}
float itemRatio = static_cast<float>(endInfo.itemIdx + 1)
                / static_cast<float>(childrenCount);
if (NearZero(itemRatio)) {
    return knownHeight; // or same known-only path
}
// … existing estimate with itemRatio
```

After fix: height props → PASS (finite, non-negative).
