## Summary

`GetInterfaceTrafficByType` reads a sysfs statistics counter
(`rx_bytes`, `tx_bytes`, `rx_packets`, `tx_packets`) into a 100-byte buffer,
but the pre-fix `read` length was `sizeof(long)` — 8 bytes on LP64. `atol`
then parsed only that prefix. `"100000000\n"` came back as `10000000`.

Callers `GetAllRxTraffic`, `GetAllTxTraffic`, and `GetInterfaceTraffic` add
that value and expose it, so data-usage accounting is low by one or more
orders of magnitude once a counter passes about 95 MiB or 1e8 packets. No
crash, no error return. The call looks successful.

Two properties failed on the same `read`: `DecimalRoundTrip` and
`FullFileParseAgreesWithWrittenValue`. One defect, not two.

Confirmed and fixed under `DTS2026083022516`. Landed in
[openharmony/communication_netmanager_base!4736](https://gitcode.com/openharmony/communication_netmanager_base/merge_requests/4736)
(`告警处理`, `e1e7b6b42`): `read(fd, buf, sizeof(buf) - 1)`.

## Vulnerable Code

`services/netmanagernative/src/manager/traffic_manager.cpp` (pre-fix, ~86):

```cpp
char buf[100] = {0};
int nread = read(fd, buf, sizeof(long));  // 8 on LP64, not sizeof(buf)
// ...
return atol(buf);  // "100000000\n" → 10000000
```

Call chain: `TrafficManager::GetAllRxTraffic` / `GetAllTxTraffic` /
`GetInterfaceTraffic` → `GetInterfaceTrafficByType(baseTrafficPath, type)`.

The same-job sibling `MockNetsysNativeClient::GetInterfaceTrafficByType`
already read `sizeof(buf)` then `atol`.

## Trigger Conditions

Any interface whose sysfs counter decimal form is longer than 8 characters.
`100000000` is about 95 MiB of bytes, or 1e8 packets. Shorter counters
(including a healthy idle iface) parse correctly and hide the bug.

## Impact

High — silent under-report on the normal traffic-accounting path. Counters at
or above 1e8 are short by one or more orders of magnitude. Not a crash, UB,
or security boundary; the wrong value is published as a successful read.

## Minimal Counterexample

```
write "{dir}/rx_bytes" = "100000000\n"
GetInterfaceTrafficByType(dir + "/", "rx_bytes")  // 10000000, want 100000000
```

## How PBT Detected This

`test/pbt/netmanagernative/get_interface_traffic_by_type_pbt_test.cpp` (real
`traffic_manager.cpp`):

```
∀ n ∈ [0, LONG_MAX]. ∀ type ∈ {rx_bytes, tx_bytes, rx_packets, tx_packets}.
  WriteDecimalNL(dir/type, n) ⇒ GetInterfaceTrafficByType(dir+"/", type) = n
```

`DecimalRoundTrip` shrank to `10000000 == 100000000`.
`FullFileParseAgreesWithWrittenValue` (digit strings up to 20 characters,
differential against the mock sibling's full-buffer read) failed on the same
witness. Seed `15500405425903927844`.

## Suggested Fix

Read the rest of the buffer and leave a trailing NUL, as landed in `e1e7b6b42`:

```diff
-    int nread = read(fd, buf, sizeof(long));
+    int nread = read(fd, buf, sizeof(buf) - 1);
```
