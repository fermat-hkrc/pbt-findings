## Summary

DNS-SD TXT records are packed as `[len][key][=value]…`. `RemoveData` copies
the stored key at the cursor into `tmp`, then matches with

```cpp
std::string tmp(dataStr, aDataStart + 1, key.length());
std::transform(tmp.begin(), tmp.end(), tmp.begin(), ::tolower);
if (dataStr == tmp) {   // BUG: entire packed blob vs the key-length slice
```

`dataStr` is the **entire** packed blob, so the equality is never true
(unless the blob is exactly the key). Consequences:

- `RemoveData` always returns `-1` — public remove never matches
- `SetRecord` upsert (`wifi_p2p_dns_txt_record.cpp:124`: remove first, else
  append) never replaces → duplicate key entries accumulate
  (`SetRecord("a",""); SetRecord("a","") → KeyNum()==2`, expected 1)

The match should be `key` vs `tmp` (the already-isolated, already-lowered
slice), not blob vs `tmp`. In-tree producer
(`WifiP2PDnsSdServiceInfo::Create` walking a `std::map`) never duplicates
keys itself, which masks the bug on the default path.

Confirmed and fixed under `DTS2026082741568` (internal DTS system).

## Vulnerable Code

```cpp
for (int index = 0; aDataStart < data.size(); ++index) {
    unsigned long aDataLength = data[aDataStart];
    ...
    std::string tmp(dataStr, aDataStart + 1, key.length());
    std::transform(tmp.begin(), tmp.end(), tmp.begin(), ::tolower);
    if (dataStr == tmp) { ... return index; }   // whole blob == key slice: never
    aDataStart += (aDataLength + 1) & 0xff;
}
```

## Trigger Conditions

Any `WifiP2PDnsTxtRecord::RemoveData(key)` on a record that contains the key,
and any `SetRecord` upsert of an existing key (public remove/upsert API;
JS/native P2P service-info paths).

## Impact

Medium — the public remove/upsert path never matches; duplicate entries on
repeated `SetRecord`. No crash.

## Minimal Counterexample

```cpp
rec.SetRecord("a", "");
rec.RemoveData("a");   // -1, expected 0
rec.SetRecord("a", "");
rec.KeyNum();          // 2, expected 1
```

## How PBT Detected This

`pbt-native/removedata_pbt_test.cpp` against the real
`wifi_p2p_dns_txt_record.cpp`. Reference oracle — the header contract
("remove the corresponding data based on the key; success = index, else
-1") plus the upsert invariant `SetRecord∘SetRecord(k,·) ⇒ KeyNum()==1`;
both FAIL, shrinking to a single `"a"` key.

## Suggested Fix

Compare the isolated slice, with the argument folded the same way:

```diff
-    if (dataStr == tmp) {
+    std::string keyLower(key);
+    std::transform(keyLower.begin(), keyLower.end(), keyLower.begin(), ::tolower);
+    if (keyLower == tmp) {
```
