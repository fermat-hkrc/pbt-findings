## Summary

`ClassicUtils::ConvertHexStringToInt` walks the input in 2-char steps and
calls `std::stol(..., 16)` with no validation and no `try/catch`:

1. **Uncaught throw (DoS).** `"ZZ"` → `std::invalid_argument` escapes →
   bluetooth service `std::terminate`.
2. **Silent prefix parse.** `"1G3F"` → `[0x01, 0x3F]`. `stol` stops at the
   first non-hex char and returns the leading value; no error.
3. **Odd length.** `"ABC"` → `[0xAB, 0x0C]`. The leftover nibble becomes a
   byte that was never in the input.

Callers restore paired-device link keys and HID descriptors from config.
Confirmed and fixed under `DTS2026063027223`.

## Vulnerable Code

`services/bluetooth/service/src/classic/classic_utils.cpp` (~44–50):

```cpp
void ClassicUtils::ConvertHexStringToInt(const std::string &str, std::vector<uint8_t> &value)
{
    for (size_t i = 0; i < str.size(); i = i + 2) {
        long k = std::stol(str.substr(i, 2), nullptr, 16);
        value.push_back(k);
    }
}
```

Sibling `BleUtils::ConvertHexStringToInt` (`ble_utils.cpp:45`) is the same
loop (IRK/LTK/CSRK restore).

## Trigger Conditions

1. Config string is not even-length `[0-9A-Fa-f]+` (corrupt file, hand edit,
   or a non-hex pair written into the store).
2. Load path calls the converter:
   - `ClassicAdapterProperties` — `GetRemoteLinkkey` → link key
   - `ClassicAdapter::GetHidDescInfo` — HID descriptor
3. `"ZZ"`-class pair throws; `"1G…"`-class pair returns wrong bytes.

Unaffected: output of `ConvertIntToHexString` (always even, hex digits only).

## Impact

| Input | Expected | Actual |
|---|---|---|
| `"ZZ"` | reject | **`std::invalid_argument` uncaught** |
| `"1G3F"` | reject | `[0x01, 0x3F]` (silent) |
| `"ABC"` | reject | `[0xAB, 0x0C]` |
| `"ABCD"` | `[0xAB, 0xCD]` | OK |

High: uncaught exception kills the service. Mixed/odd input is silent
corruption (wrong link key / HID desc, no error).

## Minimal Counterexample

```text
ConvertHexStringToInt("ZZ", out)     // throws std::invalid_argument
ConvertHexStringToInt("1G3F", out)   // out = [0x01, 0x3F]
ConvertHexStringToInt("ABC", out)    // out = [0xAB, 0x0C]
```

## Suggested Fix

Reject odd length and non-hex explicitly; no exceptions across the boundary:

```cpp
bool ClassicUtils::ConvertHexStringToInt(const std::string &str, std::vector<uint8_t> &value)
{
    if (str.size() % 2 != 0) return false;
    auto nib = [](unsigned char c) -> int {
        if (c >= '0' && c <= '9') return c - '0';
        if (c >= 'A' && c <= 'F') return c - 'A' + 10;
        if (c >= 'a' && c <= 'f') return c - 'a' + 10;
        return -1;
    };
    for (size_t i = 0; i < str.size(); i += 2) {
        int hi = nib(str[i]), lo = nib(str[i + 1]);
        if (hi < 0 || lo < 0) return false;
        value.push_back(static_cast<uint8_t>((hi << 4) | lo));
    }
    return true;
}
```
