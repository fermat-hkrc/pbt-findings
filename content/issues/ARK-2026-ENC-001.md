## Summary

`Utf16ToUTF8Bytes` (historical name: emits **UTF-16LE bytes**, not UTF-8) encodes
supplementary-plane code points for `@ohos.buffer` `utf16le` / `ucs2` / `ucs-2`.
The low-surrogate line ANDs the residual with `LOW_AGENT_MASK` (`0xDC00`) instead
of the low-10-bit mask `0x03FF`. Because `(x & M) | M == M`, every low unit is
stuck at `U+DC00`, so the Buffer holds a **different** character (silent wrong
result). High-surrogate line in the same function is already correct.

In-tree sibling `Utf8ToUtf16LEToData` uses
`(codePoint & LOWER_10_BITS_MASK) | LOW_AGENT_MASK` with
`LOWER_10_BITS_MASK = 0x03FFU`. Confirmed and fixed under `DTS2026081716365`
(internal system).

## Vulnerable Code

`static_core/plugins/ets/runtime/intrinsics/helpers/array_buffer_helper.cpp` ~378:

```cpp
uint16_t lowSurrogate = ((codePoint & LOW_AGENT_MASK) | LOW_AGENT_MASK);
// LOW_AGENT_MASK = 0xDC00 — used as both extract mask and prefix
```

Needed (sibling `ani_textencoder_helper.cpp`):

```cpp
uint16_t lowSurrogate = ((codePoint & 0x03FFU) | LOW_AGENT_MASK);
```

## Contract

For residual `cp = codePoint - 0x10000` (after plane subtract):

- high = `(cp >> 10) | 0xD800`
- low  = `(cp & 0x03FF) | 0xDC00`

## Minimal Counterexample

| Input | Expected low | Actual low | Decodes as |
|-------|--------------|------------|------------|
| U+10000 | `0xDC00` | `0xDC00` | U+10000 (accidentally OK) |
| U+10300 | `0xDF00` | `0xDC00` | U+10000 |
| U+1F4A9 💩 | `0xDCA9` | `0xDC00` | U+1F400 🐀 |

Correct only when `(codePoint - 0x10000) & 0x3FF == 0`.

## How PBT Detected This

Harness: `pbt-native/new_bugs_pbt_test.cpp` (models the production low-surrogate
formula; `Utf16ToUTF8Bytes` is `static` in an ETS-runtime TU).

| Property | Result (unfixed SUT) |
|---|---|
| BMP / accidental residual&0x3FF==0 | PASS |
| Supplementary low-surrogate ≡ sibling 0x3FF extract | FAIL |

## Impact

| Axis | Rating |
|------|--------|
| Impact when hit | Silent wrong UTF-16LE character in Buffer |
| Likelihood | Every supplementary plane code point on utf16le/ucs2 path |
| Crash / OOB / security decision | No |
| Overall | **Medium** |

Live path: `ConvertUtf16ToBytes` → `ConvertStringToBytes` →
`ConvertEtsStringToBytes` / `EtsArrayBufferFromEncodedString` (`@ohos.buffer`).

## Suggested Fix

```cpp
uint16_t lowSurrogate = ((codePoint & 0x03FFU) | LOW_AGENT_MASK);
// or introduce LOWER_10_BITS_MASK = 0x03FFU like the sibling
```
